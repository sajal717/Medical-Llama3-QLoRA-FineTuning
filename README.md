# Medical Language Model Fine-Tuning using QLoRA & Unsloth

##  Project Overview
Fine-tuned Meta's **Llama-3-8B-Instruct** model on the medical reasoning dataset using **Unsloth** and **4-bit QLoRA** in Google Colab.
